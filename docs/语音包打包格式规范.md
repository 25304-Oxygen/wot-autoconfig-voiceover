# 语音包打包格式规范

这个文档介绍语音包管理插件（AutoConfigVoiceover）可识别的第三方语音包格式，以及语音修改功能的使用。
字幕引擎只做概述，具体内容以《字幕引擎使用指南》发布后为准。

> 约定：所有 JSON 文件都支持 `//` 行注释（JSONC），可用注释解释字段含义。

---

## 1. 总览

### 1.1 安装位置

与其他 wotmod 一样，放在此路径下生效：`<坦克世界安装目录>/mods/<当前版本号>/`

### 1.2 目录结构

wotmod 内的一般结构如下：

```
voiceover.wotmod/
└── res/
    ├── audioww/
    │   └── <path_to_your_bnk>/
    │       ├── voiceover.bnk              音频库（位置由 pack.json 的 path 指定）
    │       └── inbattle_communication_*.bnk   （可选，随 voiceover.bnk 自动加载）
    └── mods/
        └── voiceover/
            └── <pack_id>/
                ├── pack.json              ★ 必需，仅此一个必需文件
                ├── subtitles/             字幕子树（可选，见《字幕引擎使用指南》）
                │   ├── XXXstyles.json     第一个合法的 .json 文件视为样式文件
                │   ├── sentences/         句子文件（文件名 = 音频内嵌 marker 名）
                │   └── images/            字幕图片加载时的根目录
                ├── bgimgs/                菜单背景图（可选）
                │   ├── menu.png           圆形图标（始终跟随活跃语音包）
                │   ├── panel.png          圆角矩形面板背景
                │   └── page.png           直角矩形面板背景
                ├── icons/                 菜单左侧导航按钮图标（可选）
                │   ├── settings.png       设置图标
                │   ├── voice.png          语音图标
                │   └── help.png           帮助图标
                ├── events.json            试听事件列表（可选，用于覆盖原列表）
                ├── remap.json             声音重映射表（可选，优先于 audio_mods.xml）
                ├── audio_mods.xml         声音重映射表（按官方格式进行解析）
                ├── attach.json            声音绑定方案（可选）
                ├── info.html / info.txt   语音包信息面板（可选）
                └── theme.json             额外颜色主题（可选）
```

目录名（pack_id，一个 voiceover.wotmod 可以同时包含多个这样的目录）即语音 ID，用于识别、
切换与注册。游戏引擎所用的虚拟文件系统（VFS）不支持解析中文路径，因此所有文件及文件夹都
应当使用**英文**。

插件扫描语音包时期只读取 `pack.json` 并对 bnk 进行校验与注册，其余可选资源在语音**被激活**时才进行解析。

## 2. pack.json（必需）

```json
{
    "path": "audioww/my_pack/voiceover.bnk",
    "name": "我的语音包"
}
```

| 键 | 必填 | 说明 |
|:--|:--|:--|
| `path` | 是 | 从 `res/` 出发指向 `voiceover.bnk` 的 VFS 路径 |
| `name` | 是 | 语音包显示名（菜单/设置里展示的中文名） |

- 缺任一键、或 `path` 指向的 bnk 不存在 → 整个包被跳过，并打印相关日志。
- 若 pack_id 与游戏现有声音模式重名 → 跳过注册（你仍可通过合适的 bnk 路径来覆盖游戏内置的画外音）。

> `voiceover.bnk` 直接放 `audioww/` 根下也允许（将覆盖默认的画外音），
> 但不推荐。

## 3. 菜单背景与颜色个性化：bgimgs/ 与 icons/

语音包可以提供自定义菜单图片。文件缺失时对应组件保持默认外观。

| 文件 | 菜单组件 | 说明 |
|:--|:--|:--|
| `bgimgs/menu.png` | 圆形图标（控制菜单收展） | **始终跟随当前活跃语音包**，独立于背景图标方案 |
| `bgimgs/panel.png` | 圆角矩形面板背景 | 属于"背景图标"方案，悬浮于背景色块 |
| `bgimgs/page.png` | 直角矩形面板背景 | 属于"背景图标"方案，悬浮于背景色块 |
| `icons/settings.png` | 左侧设置导航按钮图标 | 属于"背景图标"方案，替换原色块 |
| `icons/voice.png` | 左侧语音导航按钮图标 | 属于"背景图标"方案，替换原色块 |
| `icons/help.png` | 左侧帮助导航图标 | 属于"背景图标"方案，替换原色块 |

- 这几处图片格式固定为 PNG。
- 圆形图标 `menu.png` 不受"背景图标"方案控制，永远取自当前活跃语音包。

## 4. 试听事件列表 events.json（可选）

设置页"试听"按钮播放哪些事件。与插件自带事件格式一致：

```json
[
    {
        "text": "切换语音包时播放",
        "event": "vo_selected"
    },
    {
        "text": "战斗开始",
        "event": "vo_start_battle"
    }
]
```

| 键 | 说明 |
|:--|:--|
| `text` | 试听按钮上显示的文字 |
| `event` | 要播放的 Wwise 事件名 |

**只要此文件存在且至少一条有效条目，就整包替换**全局事件列表
（不做合并）；无文件/无有效条目 → 回退全局 `playEvent.json`。

> 开启相关设置后，切换语音包时固定播放 “vo_selected”，你可以使用
> [声音重映射](#5-声音重映射-remapjson可选) 功能来修改它。

---

## 5. 声音重映射 remap.json（可选）

把游戏事件重定向到语音包自己的事件，并支持跟随语音包动态切换。
优先读取 `remap.json`；不存在时回退同目录下的 `audio_mods.xml`
（按官方格式进行解析）。

```json
{
    "vo_original_event": "vo_my_event",
    "vo_annoying": ""
}
```

- 键值对为 { `"原始事件名"`: `"替换后的事件名"` }。
- **值为空**时可用于静音该事件。
- 不在表内的事件不受影响。

启用条件：设置页勾选允许声音重映射。

以下情境适用于声音重映射：灯泡声音替换、火炮预警声音替换、发现敌人提示音替换
装填音效替换（你也可以通过在 voiceover.bnk 中创建同名事件来替换此音效），等等

### audio_mods.xml （效果相同的替代文件）

```xml
<!-- 写法 1 -->
<root>
    <events>
        <event name="lightbulb" mod="lightbulb_mod"/>
        <event name="lightbulb_02" mod="mod_lightbulb_02"/>
    </events>
</root>
```

```xml
<!-- 写法 2 -->
<root>
    <events>
        <event>
            <name>lightbulb</name>
            <mod>mod_lightbulb</mod>
        </event>
        <event>
            <name>lightbulb_02</name>
            <mod>lightbulb_02_mod</mod>
        </event>
    </events>
</root>
```

> 官方格式的 `<loadBanks>` 段会被忽略，插件暂时没有音效声音库的加载、切
> 换与管理相关的功能。

## 6. 声音绑定方案 attach.json（可选）

主动播放：**某些声音/指令触发后，额外播放一段指定语音**，
用于丰富语音包体验，例如你可以将事件绑定在受击（如跳弹/未击穿/被击穿）音效上。

```json
{
    "sound": [
        {
            "match": ["psb_main", "PC"],
            // 如例，当开炮音效播放后
            "event": "vo_shoot"
            // 播放 WWISE Event: vo_shoot
        },
        {
            "match": "vo_engine_damaged",
            "event": "vo_oops",
            "strict": true
        }
    ],
    "cmd": [
        {
            "match": "affirmative",
            "event": "vo_affirm"
        }
    ]
}
```

| 键 | 说明 |
|:--|:--|
| `sound` | 声音规则数组：游戏播放某 Wwise 事件时触发 |
| `cmd` | 指令规则数组：**玩家自己**发送某快捷指令时触发 |
| `match` | 匹配关键词。字符串或字符串数组；默认 AND 子串包含（大小写不敏感） |
| `event` | 命中后要播放的事件名，或事件名数组（全部依次播放） |
| `strict` | 可选，使用布尔值。`true` 时关键词必须与事件名**完全相等**（用于区分共享前缀的事件或命令） |

匹配规则示例：

- `"match": ["psb_main", "PC"]` → 事件名同时包含 `psb_main` 和 `PC` 才命中（AND）。
- `"match": "affirmative"`（cmd）→ 拦截客户端 i18n key 并尝试匹配
（如 `#ingame_gui:chat_shortcuts/affirmative`）包含 `affirmative` 即命中。
- 多条规则可同时命中 → 按规则顺序播放所有目标事件。

启用条件：设置页勾选允许声音绑定。

以下情境适用于声音绑定：快捷指定发出后播放某声音，开火后播放某声音，
被击中、锄大地时播放某声音，敌友阵亡后播放某声音，等等

> 注意：不是所有音效都能实现绑定触发，极个别的例如**装填音效**就在技术上难以
> 实现绑定，对于该音效，你可以选择在 voiceover.bnk 中创建同名事件来覆盖
> 它，或是使用声音重映射。

## 7. 语音包介绍 info.html / info.txt（可选）

在语音包详情页渲染。**`info.html` 优先，无则回退 `info.txt`。**

> ★ **首字符丢弃**：文件第一个字符必须是**非空格**字符。
> 引擎会把以 `<` 开头的文本当作 XML 解析导致读取失败，因此首个字符
> 是"保护位"，读取时会被丢弃。建议用一个不可见字符 `\0`，或一个
> 不影响显示的标记字符（如 `#`）：

```
实际文件内容:  \0<html><body><p>这是我的语音包</p></body></html>
读取到的文本:  <html><body><p>这是我的语音包</p></body></html>
```

`info.html` 的内容以富文本渲染，`info.txt` 以纯文本渲染。

> 附：HTML 常见转义字符列表

| 字符 | 转义字符 |
| :-- | :-- |
| & | `&amp;` |
| " | `&quot;` |
| < | `&lt;` |
| > | `&gt;` |

```
==== 使用示例 ====
实际文件内容:  Ciallo～(∠．ω&lt; )⌒★
渲染出的内容:  Ciallo～(∠・ω< )⌒★
（坦克世界中分隔符“．”渲染出来的样子等同于“・”）
```

在富文本中 `<p>` 标签是核心，所有内容必须放在 `<p>` 标签内部才能被识别。
支持的 HTML 标签：

| 标签 | 含义 | 用法 |
| :-- | :-- | :-- |
| `<p>` | 用于表示段落 | 以下属性可用：`align="left\|center\|right"`、`size`、`color` |
| `<font>` | 用于调整字号和颜色 | 以下属性可用：`size`、`color` |
| `<b>` | 用于加粗 | `<b>`**加粗文本**`</b>` |
| `<u>` | 添加下划线 | `<u>`<u>下划线</u>`</u>` |
| `<a>` | 可点超链接，无悬停变色效果，不自带下划线 | `<a href="event:https://github.com">` 超链接文本 `</a>` |
| `<img>` | 添加图片 | 必须是 `<p>` 块的唯一内容，含 `<img>` 的 `<p>` 不会渲染文本。以下属性可用：`align="left\|center\|right"`、`width`、`height` |

图片格式详解（支持 .jpg、.png，但不支持 .gif）

> `<p align="center"><img src="mods/acv/image.png" width="200" height="100"/></p>`

| 属性 | 必填 | 说明 |
| :-- | :-- | :-- |
| src | 是 | 路径，自动处理 mods/ → ../../ 转换 |
| width | 否 | 指定宽度（px），不指定则用图片实际宽度，超 IMG_MAX_W 自动等比缩小 |
| height | 否 | 指定高度，同时指定 width+height → 拉伸到精确尺寸 |

## 8. 额外颜色主题 theme.json（可选）

语音包可以自带一套菜单颜色主题，出现在设置页"颜色方案"下拉中。

```json
{
    "name":          "深色主题",
    "surface0":      "0x1E1E1E",
    "surface1":      "0x2D2D2D",
    "surface2":      "0x3C3C3C",
    "surface3":      "0x252526",
    "accent":        "0x3D6B9B",
    "accentHover":   "0x4D8BC5",
    "accentPress":   "0x2D5B7B",
    "stroke":        "0x888888",
    "textPrimary":   "0xD4D4D4",
    "textSecondary": "0x666666",
    "titleText":     "0xFFFFFF",
    "sbThumb":       "0x666666",
    "sbBtn":         "0x555555",
    "sbBtnArrow":    "0xCCCCCC"
}
```

- `name` 必填（即下拉里的显示名）。
- 颜色值两种格式均可：`"#RRGGBB"` 或 `"0xRRGGBB"`。
- 未声明的槽位自动取默认色板（Dark+），无需全部填写。

| 槽位 | 用途 |
|:--|:--|
| `surface0` ~ `surface3` | 面板/弹窗/输入框/下拉行等表面色 |
| `accent` / `accentHover` / `accentPress` | 主色调、悬停、按下 |
| `stroke` | 组件描边 |
| `textPrimary` / `textSecondary` | 正文 / 次要文字 |
| `titleText` | 菜单大标题颜色 |
| `sbThumb` / `sbBtn` / `sbBtnArrow` | 滚动条拇指 / 按钮 / 箭头 |

## 9. 字幕子树 subtitles/（可选）

语音包可携带字幕，让语音播放时屏幕显示对应文字。详细规范见
**《字幕引擎使用指南》**。此处只列结构：

```
subtitles/
├── XXXstyles.json        样式文件（目录下第一个合法的 .json），若不存在则字幕功能不开放
├── sentences/            句子文件（文件名 = 音频内嵌 marker 名）
│   ├── <marker>.json
│   └── template.json     位置编辑预览用（可选，缺省时取第一个合法句子文件）
└── images/               字幕图片（JSON 中 img 路径相对此目录）
```

## 10. 常见问题

**Q1: 包放进 mods/<当前版本号>/ 后游戏里看不到？**

A: 检查 pack.json 是否缺键；bnk 路径是否存在；pack_id 是否与游戏现有模式重名。
改动后需重启游戏。

**Q2: 语音能播但字幕不出来？**

A: 待《字幕引擎使用指南》发布后查看 FAQ。最可能是：样式文件缺失/无样式段、
句子文件名与音频 marker 名不一致、文件名含中文。

**Q3: 图片不显示？**

A: 检查文件名是否为纯英文、路径是否与 JSON 中一致（相对 `subtitles/images/`）。

**Q4: 内置语音包能做这些吗？**

A: 不能。`mods/voiceover/` 仅扫描第三方语音包；内置语音无这些可选资源，
并且内置语音所含的音频文件天然缺失 Marker。
