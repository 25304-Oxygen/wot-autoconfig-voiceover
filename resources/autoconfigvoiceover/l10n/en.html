Plugin Introduction


This is a mod that makes voice packs compatible with each other. Supported features:

．Voice Enhancement: Expands the scope and triggers of voice modification. By attaching a file in a specified format to a voice pack, you can replace any sound driven by a WWISE Event, and also play specified sounds when certain sounds play or commands are issued.
．Special Voice Override: When you enter a battle with a commander that carries a voice pack, the special voice is forced back to the voice pack currently selected in this plugin. For normal commanders, no forced change is applied — you can still switch voices anytime from the game settings menu without opening the plugin panel. That said, switching through the plugin is still recommended.
．Subtitle Rendering: Implements a feature similar to the official Girls und Panzer subtitle plugin. By attaching a file in a specified format to a voice pack, you can achieve a wide variety of subtitle visual effects, with maximum DIY support and an optimized subtitle queue.
．Other Features: Implements a feature similar to spotted shout, letting you edit your shout text, and also lets you replace the in-game quick chat messages. The edited quick chat text is only visible to you. These features are unrelated to sound modification.


Files and Explanation


The plugin stores its data on disk at runtime. Delete a file to restore its default. Storage directory: {0}

．bgimgs folder: Background images used by the plugin (menu.png, panel.png, page.png — 260x260, 620x260, 680x500 pixels respectively). You can replace them.
．icons folder: Left navigation icons (help.png, settings.png, voice.png — 84x84 pixels; 64x64 is recommended). You can replace them.
．jsons folder: gameSoundModes.json (built-in voice pack list — edit names and volumes, reorder), hotkey.json (hotkey codes for selecting and setting the hotkey), ingameGuiText.json (quick chat message codes for in-game text replacement), personal_settings.json (spotted shout and quick message replacement), playEvent.json (sound playlist — plays sounds by event name), theme.json (UI color scheme table — editable), voiceover.json (third-party voice pack list — volume editable)
．l10n folder: UI translations. Editable.
．subtitles folder: Saves the subtitle component offsets of each subtitle voice pack. Simple and standard modes save offsets independently.
．config.json: Configuration file.
．script.log: Runtime log. The log output level can be changed in settings.


FAQ


Q1: I cannot find the voice pack I downloaded?
A: Voice packs must be in .wotmod format and organized in the specified way.
Q2: I installed a .wotmod voice pack but it is not found?
A: This is usually caused by an incorrect file structure. Go to the config folder, open script.log and check the error.
Q3: I want to package a voice pack myself. How?
A: You can find a text tutorial in the GitHub repository.
Q4: I want to learn how to make a subtitle voice pack?
A: The tutorials will be posted on both Bilibili AND GitHub repository. Wait with patience.
